# Discover Project README scope

Inspect the complete repository evidence for maintained Projects: manifests,
workspace and build configuration, existing documentation, maintained source,
and meaningful component boundaries. A Project is a maintained app, service,
library, or tool with its own responsibility and development commands,
including internal packages. Directory names and conventional layouts alone do
not establish membership. Exclude fixtures, generated output, and directories
that only organize other content.

Propose one individual non-root `README.md` path for every Project. Include an
existing README when present. For a missing README, include its intended path
with absence evidence and positive evidence for the Project. Record each
relevant candidate as included or excluded with a reason, explain how the paths
cover every Project, and disclose unresolved membership questions. Do not
propose directory trees, globs, the root README, exact-owned files, or paths
owned by another declaration.
