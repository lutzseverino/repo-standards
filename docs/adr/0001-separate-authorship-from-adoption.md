# Separate standards authorship from adoption execution

Standards repositories supply complete profiles, content, guidance, skills, and
trusted checks and fixes, while Repository Standards owns resolution and the
adoption procedure. This permits independently authored standards without an
author-specific workflow engine: one profile resolves through defaults and
whole-declaration replacement or exclusion, and all adoption uses the same CLI
and system skill. The trade-off deliberately excludes profile composition and
adoption hooks from version one.
