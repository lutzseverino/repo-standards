# Getting started

These pages introduce Repo Standards to a first-time reader, from what it does to keeping an adoption current.

- [What Repo Standards does](what-repo-standards-does.md): the problem it
  solves, who it is for, and the terms the other pages use.
- [Adopt Repo Canon in five minutes](adopt-repo-canon.md): adopt a ready-made
  setup with your coding agent or at a terminal, then review what changed.
- [Keep it up to date](keep-it-up-to-date.md): see what is available, update
  with one command, or opt in to automated update pull requests.
