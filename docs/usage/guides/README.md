# Guides

These guides walk through the tasks of using Repo Standards, from adopting a standards source to publishing your own.

- [Adopt a standards source](adopt.md): adopt with one command, with your
  coding agent or at a terminal, then review the changes, commit them, and
  recover a stopped run.
- [Update an adoption](update.md): see what is available, update with one
  command, apply the same version again, change the CLI pin, and update
  unattended.
- [Run the adopted checks](run-checks.md): check work against the adopted
  standards with `check`, read the result, and fix a failure.
- [Automated updates](automated-updates.md): the update action that proposes
  every available update through one rolling pull request or issue.
- [Install the CLI and skills](install.md): installing the CLI outside a
  project, the standalone bootstrap, and the adoption and authoring skills.
- [Write and publish a standards source](author-a-source.md): writing,
  validating, publishing and evolving your own setup.
- [Find standards sources](find-sources.md): searching the public
  `repo-standards` topic for sources to adopt.
