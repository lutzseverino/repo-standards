# Project documentation guidance

Give each maintained project a concise README with its purpose, verified setup
and operating commands, and links to deeper material. Preserve useful facts,
warnings, and recovery instructions when moving existing documentation into
`docs/projects/`. Add the smallest useful documentation index and repair links
that referred to old locations.

Do not rewrite generated or fixture content, invent commands, or describe an
organizational directory as a project. Preserve project-owned voice and history.
The exact `docs/catalog.json` is outside this contextual declaration.
