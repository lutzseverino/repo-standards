# Generated shadcn source

Every TypeScript file in this directory is shadcn registry output, generated by
the pinned shadcn CLI. Treat it as read-only.

- Do not create, edit, format, rename or delete these files by hand.
- Add a component with `pnpm --dir site ui:add <component...>`, and refresh the
  installed ones with `pnpm --dir site ui:update`, from the repository root.
- Import components from `../app/`, never from here.
- Put a shared rule in a lean wrapper in `../app/`, and styling that applies to
  every component of a kind in a stylesheet that targets its `data-slot`.

`pnpm --dir site ui:check` fails when this directory differs from the checksums
in `registry-manifest.json`.
