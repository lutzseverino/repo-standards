Repo Canon es una configuración lista para empezar. Tu agente de programación la instala en tu repositorio y la adapta a tu proyecto, y más adelante el mismo prompt la actualiza a una versión más reciente.

## AGENTS.md

Un AGENTS.md que los agentes de programación leen primero, con la documentación del proyecto para agentes al lado, en docs/agents/.

## Skills para agentes

Skills en .agents/skills/ para triaje, especificaciones y tickets, desarrollo guiado por pruebas, revisión de código y pull requests.

## Guía de contribución

Un CONTRIBUTING.md para las personas y los agentes que trabajan en el repositorio.

## Plantillas de issues y PR

Formularios de issues de GitHub para informes de errores, solicitudes de funcionalidades, especificaciones y tickets de implementación, y una plantilla de pull request.

## Comprobaciones

Comprobaciones de la navegación de la documentación, la estructura de los README y el archivo de revisores de pull requests, que se ejecutan al adoptar y con repo-standards check, y flujos de trabajo de GitHub Actions, entre ellos comprobaciones de los contratos de issues y de los metadatos de las pull requests.
