Repo Canon és una configuració a punt per començar. El teu agent la instal·la al teu repositori i l'adapta al teu projecte, i més endavant el mateix prompt l'actualitza a una versió més nova.

## AGENTS.md

Un AGENTS.md que els agents llegeixen primer, amb la documentació del projecte per a agents al costat, a docs/agents/.

## Skills per a agents

Skills a .agents/skills/ per a triatge, especificacions i tiquets, desenvolupament guiat per proves, revisió de codi i pull requests.

## Guia de contribució

Un CONTRIBUTING.md per a les persones i els agents que treballen al repositori.

## Plantilles d'issues i de PR

Formularis d'issues de GitHub per a informes d'errors, sol·licituds de funcionalitats, especificacions i tiquets d'implementació, i una plantilla de pull request.

## Comprovacions

Comprovacions de la navegació de la documentació, l'estructura dels README i el fitxer de revisors de pull requests, que s'executen en adoptar i amb repo-standards check, i fluxos de treball de GitHub Actions, entre els quals comprovacions dels contractes d'issues i de les metadades de les pull requests.
