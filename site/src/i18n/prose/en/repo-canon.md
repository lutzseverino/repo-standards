Repo Canon is a ready-made setup to start from. Your coding agent installs it in your repository and adapts it to your project, and the same prompt later updates it to a newer release.

## AGENTS.md

An AGENTS.md that coding agents read first, with the project's agent docs beside it in docs/agents/.

## Agent skills

Skills in .agents/skills/ for triage, specifications and tickets, test-driven development, code review and pull requests.

## Contribution guidelines

A CONTRIBUTING.md for the people and the agents who work on the repository.

## Issue and PR templates

GitHub issue forms for bug reports, feature requests, specifications and implementation tickets, and a pull request template.

## Checks

Checks of the documentation's navigation, the READMEs' structure and the pull request reviewer file, run on adoption and with repo-standards check, and GitHub Actions workflows, among them checks of issue contracts and pull request metadata.
